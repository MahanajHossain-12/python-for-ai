# Learning Python for AI & Applied Data Science

This repository serves as a portfolio of hands-on technical exercises, data analysis pipelines, and object-oriented programming (OOP) implementations.

--- 

## Focus Areas & Learning Objectives

* **Object-Oriented Programming (OOP):** Writing clean, modular Python code using classes, inheritance, encapsulation, and custom validation frameworks.
* **Data Processing & Analytics:** Parsing, cleaning, and aggregating structured data using standard libraries and environment tools.
* **Data Visualization:** Generating automated charts and summary outputs from dynamic datasets (e.g., weather trends and sales metrics).
* **Scripting & API Configurations:** Building reusable helper modules and structured configs for downstream AI integration.
